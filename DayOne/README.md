# Day 1 - 30 Days of Three.js

Welcome to Day 1 of my 30 Days of Three.js journey! 🚀

## Overview
This is the starting point of the project where the basic Three.js boilerplate is set up. The environment is configured with a scene, a camera, and a renderer to display 3D content on the web.

## Tech Stack
- HTML / CSS / JavaScript
- [Three.js](https://threejs.org/)
- Vite (Development Server)

## How to run
1. Install dependencies: `npm install`
2. Start the dev server: `npm run dev`
